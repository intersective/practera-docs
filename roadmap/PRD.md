An interactive roadmap for Practera's products. Sync'ed with JIRA & github so it has up-to-date status on all projects & tasks. Uses AI to make recommendations on prioritization based on business goals. Hosted on AWS using the practera sandbox AWS infrastructure. Runs locally as well.

We will need to create proper functionality documentation for all our applications in order to take a curent state assessment + look at gaps opportunities. 

We are almost ready to release the login-refactor branches which is the first step in a major refactor of Practera. When done, the only major task left will be to replace the CakePHP admin system with a nextjs admin system to match project-hub.

Past that, we can start working on new initiatives that use AI to drive business value:

1) Improving the ability to source project providers
2) Improving the ability for our customers to expand the deployment of Practera.
3) Delivering more value to our mentors and project providers. 
4) Being able to provide offerings direct to learners

The roadmap tool should be able to use AI to help us come up with prioritized initiatives against these goals that are practical given the current tech state.
